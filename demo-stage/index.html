What works here, and what needs real phones and a real Fire TV

Works in this page

  • Every TV screen of the web build: home with the QR code and room code, Living room (kids channel next to captions, moments or headlines), Captions, Table Hunt, Happy moments, Settings.
  • Joining from each phone frame (name, language, consent). Each frame is a separate person.
  • Table Hunt using the phone's "pick from the list" option; objects and moments sent by the labelled test scripts.
  • Help mode: H on the keyboard (the ☰ key), the countdown on the TV, the alert on the other phone frames and "I'm coming". The alarm sound may need one click inside a phone frame first.

Needs real devices

  • Speech captions: this computer has one microphone, not one per person. Use real phones, or the labelled test phones node scripts/sim-phones.mjs ROOM.
  • Camera scans (Show) and smile clips (Smile). npx tsx scripts/sim-object.ts sends a labelled test photo and clip.
  • "Alexa, pause" and the real remote: only on the Fire TV stick. Here the keyboard stands in for the remote.
  • Vibration and a locked phone ringing.

The TV app is not reachable. Start the TV web preview (README, "Run it"), check the TV app URL above, then press Reload TV.
